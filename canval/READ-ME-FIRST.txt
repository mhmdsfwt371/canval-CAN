canval v1.1
===========

Unzip over D:\canval. Three files, no sample data:

    docs/index.html            the page
    canval/probe_live.py       nightly platform check
    canval/export_site.py      writes the JSON the page reads

Then:

    cd D:\canval
    git pull --no-rebase
    git add -A
    git commit -m "canval v1.1"
    git push

Then run canval nightly once from the Actions tab. Both new things in
this version come from that job, so the page cannot show them until it
has run:

  - every sensor configured on a device, marked live or silent
  - the account each device sits under, and who created it

v1.0 -> v1.1 adds only. Nothing that worked before behaves differently.
