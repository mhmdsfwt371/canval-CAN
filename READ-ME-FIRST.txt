What changed
------------
The card highlight and the tap-to-close behaviour were written in v1.3
but never reached the file: the edit script printed its success line
before saving, so when a later edit failed the whole batch rolled back
while the log still said it had worked. That is why a card would open
with no green mark and no way to close it.

Both are in now, and every piece has been read back out of the file to
prove it. Tapping a card opens it, tapping the same card again closes it,
tapping another swaps, and the Back button and Clear do the same thing
through one code path instead of three.
