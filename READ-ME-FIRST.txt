What changed
------------
Picking a year used to list every file whose range reached it, so asking
about a 2022 Suburban showed both "[13+]" and "[22+]" in one list, as if
they were equal answers. They are not: one was built for that year and
the other merely extends into it.

The file built for the chosen year now stands on its own, and the older
files sit below under "wider files that also cover it". Nothing is
hidden -- the older file is still the fallback when the closer one fails
-- but it is no longer presented as the same thing.
